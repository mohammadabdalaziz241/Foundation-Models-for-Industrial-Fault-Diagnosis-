# Repository structure

`src/methodology_v2` is executable code. `scripts/methodology_v2` contains staged audit/build/train/compression entry points. `methodology_v2` contains frozen scientific inputs and checksums, not a second implementation. `configs/dissertation` mirrors the most important frozen YAML specifications. `tests/methodology_v2` is the current pipeline test suite. `results` contains only curated pre-existing summaries and figures; its provenance map names every source.
